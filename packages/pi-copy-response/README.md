# @tifan/pi-copy-response

Pick one assistant response from the current pi session, then copy it to the system clipboard.

Use this when pi's built-in `/copy` is not enough. `/copy` copies only the last assistant response. This extension lets you choose an older response.

## Install

```bash
pi install npm:@tifan/pi-copy-response
```

## Commands

- `/copy-response`: Pick one assistant response and copy it.
