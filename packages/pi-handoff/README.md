# @tifan/pi-handoff

Transfer pi session context to a new session, and query past sessions for context, decisions, or code changes.

## Install

```bash
pi install npm:@tifan/pi-handoff
```

## Tools and commands

- `handoff` — summarize the current conversation and start a new session pre-loaded with that context.
- `session_query` — answer a question about a previous `.jsonl` pi session file.
